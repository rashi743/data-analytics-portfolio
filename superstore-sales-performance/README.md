Superstore Sales Performance Dashboard

A Power BI dashboard project analyzing sales performance, profitability, customers, products, regions, discounts, and shipping-related metrics using Superstore data.

Tools

- Power BI
- DAX
- CSV
- Data Visualization

Dataset

The project uses Superstore sales data containing 9,994 rows and 26 columns.

Project Files

- Power BI dashboard
- Superstore dataset

Dashboard

The dashboard provides analytical views of sales and profitability performance across different business dimensions.

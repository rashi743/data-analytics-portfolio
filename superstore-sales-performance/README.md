# Superstore Sales Performance Dashboard

A Power BI data analytics project focused on analyzing sales performance, profitability, customers, products, regions, discounts, and shipping performance using Superstore sales data.

## Objective

The objective of this project is to transform raw sales data into an interactive dashboard and identify patterns and insights related to sales, profit, customers, products, regional performance, discounts, and shipping.

## Tools & Technologies

- Power BI
- DAX
- CSV
- Data Visualization

## Dataset

The project uses Superstore sales data containing *9,994 rows and 26 columns*.

The dataset includes information about:

- Orders
- Customers
- Products
- Categories and sub-categories
- Sales
- Profit
- Discounts
- Regions
- Shipping
- Order dates

## Analysis Performed

The dashboard analyzes:

- Overall sales and profit performance
- Customer segments
- Product category performance
- Regional and market performance
- Profit and discount relationships
- Sales opportunities
- Shipping and delivery performance

## Dashboard

The Power BI dashboard contains multiple analytical views designed to help understand business performance from different dimensions.

### Dashboard Views

- Overview
- Customer Segment Analysis
- Product Category Performance
- Profit & Discount Analysis
- Regional Market Analysis
- Sales Pipeline & Opportunity Tracking
- Shipping & Delivery Performance
